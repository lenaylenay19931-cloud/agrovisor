Índices disponibles

Cada índice necesita bandas distintas.

RGB

VARI

Índice visible resistente a variaciones atmosféricas en ciertas condiciones. Puede estimarse con imágenes RGB.

VARI = (G − R) / (G + R − B)
Rojo + NIR

NDVI

Indicador común de verdor y actividad vegetal; no equivale por sí solo a un diagnóstico agronómico.

NDVI = (NIR − R) / (NIR + R)
Red edge + NIR

NDRE

Puede ayudar a observar variaciones de vegetación, especialmente en doseles densos, si el sensor captura red edge.

NDRE = (NIR − RE) / (NIR + RE)

Cómo interpretar los resultados

Los mapas sirven como apoyo para inspección; no sustituyen el muestreo en campo.

  • Planifica el vuelo: intenta mantener iluminación, altura y condiciones similares entre fechas.
  • Prepara las bandas: para NDVI y NDRE usa bandas exportadas y alineadas desde un flujo fotogramétrico o sensor multiespectral. Una imagen coloreada no es una banda calibrada.
  • Compara zonas y fechas: revisa patrones espaciales y cambios relativos; valida anomalías con recorridos, suelo, riego y estado fitosanitario.
  • Evita conclusiones automáticas: estrés hídrico, nutrición, sombra, suelo expuesto y diferencias de iluminación pueden producir señales parecidas.

Demostración: los datos sintéticos solo ilustran el funcionamiento visual de la página; no representan un predio real ni deben usarse para tomar decisiones agrícolas.
